## Follow-up rules (from chapter 02 and the templates' 30-day rhythm)

- [ ] Due dates get calendared the day the letter goes out, not remembered later.
- [ ] If "verified" arrives and I still believe it's wrong: one re-dispute with *new specific evidence*, dated.
- [ ] If a corrected/deleted item silently re-appears: log, then dispute citing the prior outcome.
- [ ] If deadlines blow by with no answer: [CFPB complaint](https://www.consumerfinance.gov/complaint/), free — and note the case number here: ______
- [ ] If the item never existed, it's not mine: identitytheft.gov report filed on ____ and everything above runs with that attached.

## Enclosure checklist per letter (copies only, never originals)

- [ ] Proof of the correct information (statement, letter, court paper)
- [ ] Copy of photo ID
- [ ] Proof of address (utility bill or similar)
- [ ] Copy of the report page with the error
- [ ] Identity-theft report, if that's the situation

## Freezer reminder

If an item in any row turns out not to be mine — freeze at all three bureaus ([chapter 03](03-freezes-beat-monitoring.md)) *before* mailing anything else. Order matters here.
